# Portfolio

Personal portfolio created to showcase my frontend projects, technical stack, and background as a junior frontend developer.

The goal of this project is to present my main work, describe the technologies I use, and provide a clear overview of my development path, interests, and contact information.

## Live Demo

[View Live Portfolio](https://portfoliomanucappai.netlify.app/)

## Tech Stack

This project was built with:

* React
* CSS

## Features

* Personal introduction section
* Projects showcase
* Project detail pages
* Responsive layout
* Custom navigation between sections
* Social and contact links

## Installation

To run the project locally, clone the repository:

```bash
git clone https://github.com/ManuelCappai94/Portfolio.git
```

Move into the project folder:

```bash
cd Portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

Then open the local development URL shown in the terminal.
